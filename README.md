Convexity & Sensitivity AI Agent

📌 Project Overview

The Convexity & Sensitivity AI Agent is a fixed-income analytics project designed to analyze bond portfolio risk and sensitivity to changes in interest rates and yield curves.

The project focuses on Duration, Convexity, DV01, Key Rate Duration (KRD), Yield Curve Analysis, Monte Carlo Simulation, VaR/CVaR, Machine Learning, and Portfolio Risk Analysis.

🎯 Objectives

- Analyze bond portfolio characteristics and risk.
- Calculate Duration, Convexity and DV01.
- Measure portfolio sensitivity to interest-rate changes.
- Perform Key Rate Duration analysis.
- Analyze historical yield curves.
- Generate Monte Carlo interest-rate scenarios.
- Perform stress testing.
- Calculate VaR and CVaR.
- Apply Machine Learning for bond price prediction and sensitivity analysis.
- Present results through an interactive dashboard.

📊 Main Components

1. Bond Portfolio Analysis

Analysis of bond characteristics such as:

- Coupon Rate
- Yield to Maturity
- Maturity
- Market Value
- Duration
- Convexity
- DV01
- Portfolio Weight

2. Yield Curve Analysis

Analysis of yield-curve movements including:

- Parallel shifts
- Steepening
- Flattening
- Twist
- Butterfly movements

3. Risk Metrics

The project calculates:

- Macaulay Duration
- Modified Duration
- Effective Duration
- Convexity
- DV01
- Key Rate Duration

4. Monte Carlo Simulation

Monte Carlo scenarios are used to estimate possible portfolio P&L under different yield-curve movements.

5. Stress Testing

The portfolio is tested under different interest-rate shocks such as:

- +25 bps
- +50 bps
- +100 bps
- +200 bps
- +300 bps
- -100 bps

6. VaR and CVaR

The project estimates portfolio risk using:

- Parametric VaR
- Monte Carlo VaR
- Conditional VaR (CVaR)

7. Machine Learning

Machine Learning models can be used for bond price prediction and sensitivity analysis.

Models include:

- Random Forest
- XGBoost
- Neural Network

8. Dashboard

The project dashboard presents:

- Portfolio KPIs
- Duration Contribution
- KRD Heatmap
- Yield Curve Evolution
- Monte Carlo P&L Distribution
- Risk Analysis
